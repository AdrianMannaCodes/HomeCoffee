# bundle/RedStarOS.utm

UTM bundle skeleton. config.plist is generated by scripts/gen-config-plist.js (aarch64, 512 MB, no hardware acceleration).
The disk image Data/disk.img is NOT included. It is produced by scripts/build-rootfs.sh, which has not been run yet.
Key names in config.plist are unverified against the UTM version the user runs. Check them before release.
