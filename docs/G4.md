# HomeCoffee on PowerPC G4 (experimental)

Status: experimental and unverified. The x86_64 UTM bundle (HomeCoffee-1.0.utm) is the only supported build. This page describes a separate G4 track and does not produce a working G4 image yet.

## Target
- Machine: Power Macintosh G4, emulated as QEMU `-M mac99` with the `mpc7455` (G4) CPU.
- Emulators: qemu-system-ppc (scripts/run-mac99.sh), with DingusPPC or Infinite Mac as alternatives to evaluate.
- Guest OS: a 32-bit PowerPC Linux. Alpine, the base of the x86_64 build, does not publish a PowerPC release, so this track needs a different base.

## Unverified items (must be checked before relying on this track)
- Which Debian or other distro still publishes a usable powerpc (32-bit big-endian) installer or cloud image, and whether it supports the G4 (mac99) machine.
- Whether the Chromium kiosk can run on the guest at all. Chromium is not expected to be available for 32-bit PowerPC, so the G4 display path likely needs a different browser or a non-browser UI.
- Whether mac99 networking (sungem NIC) and the Open Firmware boot path work with the chosen kernel.

## Running the script
```
sudo apt install qemu-system-ppc
scripts/run-mac99.sh path/to/disk.img
```
Optional environment variables: RAM_MB (default 512), CPU (default mpc7455), and KERNEL / INITRD for a direct kernel boot.

## Not included
- No G4 disk image is built by .github/workflows/build-utm.yml. The workflow builds x86_64 and aarch64 UTM bundles only.
- The UTM bundle format does not target PowerPC, so G4 output will not be a .utm file.
